# 💡 Bulb Switch

A simple interactive light bulb built with HTML, CSS, and JavaScript.

Click the switch to turn the bulb **on** and **off** — with a warm glow effect!

---

## ✨ Features

* Click the switch to toggle the bulb on/off
* Warm yellow glow effect when the bulb is ON
* Glowing filament animation
* Switch moves up/down like a real switch
* Fully built with HTML, CSS, and JavaScript — no libraries!

---

## 🛠️ Tech Stack

* HTML
* CSS (transitions, box-shadow, pseudo-elements)
* JavaScript (classList toggle)
